# Updating

Type:

```sh
oracle update
```

It:

1. Downloads the newest Oracle.
2. Applies any new Oracle features and fixes.
3. Updates every program on the system, including Brave.
4. Tells you if a restart is needed (for example after a new Linux kernel).

**Your settings are safe.** Oracle keeps its defaults in `~/.local/share/oracle/default/`. Your own files (`~/.config/hypr/hyprland.lua`, `~/.config/ghostty/config`, `~/.config/tmux/tmux.conf`) are never changed by an update.

**Tip:** restart after big updates. A system that runs for weeks on an old kernel can break things like graphics or USB.
